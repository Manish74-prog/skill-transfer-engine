## 1-Minute Pitch Script (Practice this!)
"Our system treats career transition like a GPS. Instead of asking someone to start from zero, we first look at the skills they already have. We identify which of those skills are transferable to different careers, find the missing skills, and generate a step-by-step roadmap. The user can also change their target career using our What-If simulator and immediately see how the required skills and roadmap change."
